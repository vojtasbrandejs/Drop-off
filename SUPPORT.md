# Support

## Questions and bugs

Check the [installation, troubleshooting, and uninstall notes](README.md) first. If the problem remains, [open an issue](../../issues) with:

- your macOS version,
- your Drop-off version,
- what you expected to happen,
- what happened instead,
- the shortest steps that reproduce it.

Please use generic file names and remove personal information from screenshots or recordings.

## Security

Do not report an undisclosed security issue in a public issue. Follow the [security policy](SECURITY.md) to send it privately.

## Privacy

Drop-off has no account or cloud service. Its local file and event handling is described in the [privacy notice](PRIVACY.md).
