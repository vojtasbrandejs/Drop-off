# Security Policy

## Supported versions

Security fixes are provided for the current 1.x release line.

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| Earlier development builds | No |

## Reporting a vulnerability

Please report suspected vulnerabilities through this repository's **Security** tab by selecting **Report a vulnerability**, which creates a [private GitHub security advisory](../../security/advisories/new).

Do not open a public issue for an undisclosed vulnerability. Include the affected version, macOS version, reproduction steps, impact, and any suggested mitigation. Please avoid including unrelated personal data or files.

## What to expect

- We aim to acknowledge a report within five business days.
- We aim to provide an initial assessment within ten business days.
- For an accepted report, we aim to provide progress updates at least every fourteen days until remediation or closure.
- We will coordinate disclosure timing with the reporter when practical. A fix may be released before technical details are published when users need time to update.

These are response targets, not guarantees. Complex reports, upstream platform behavior, or incomplete reproductions may require additional time.

The public issue tracker remains appropriate for ordinary bugs that do not create a confidentiality, integrity, privacy, or code-execution risk.
